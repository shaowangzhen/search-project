## 技术栈架构

```
┌─────────────────────────────────────────────────────────────────┐
│                        技术栈层次                                │
├─────────────────────────────────────────────────────────────────┤

│  │ Nginx           │        │  │ FastAPI 0.95.2              │  │
│  │ PHP-FPM 7.1+    │        │  │ asyncio + httpx             │  │
```
