# 官网直达搜索引擎 - 整体架构总结

## 🎯 项目概述

**官网直达**是一个专注于官方网站检索的搜索引擎，解决当前搜索引擎过度商业化、广告过多的问题。通过实时多引擎聚合和AI智能分析，为用户提供纯净、权威的官方网站搜索结果。

## 🏗️ 整体架构

### 架构演进历程

```
传统架构 → 实时搜索架构 → 当前优化架构
   ↓           ↓              ↓
数据存储    实时搜索        实时搜索 + 优化
MySQL/ES   多引擎聚合      3引擎聚合 + 智能识别
```

## 🔧 技术栈详情

### 前端技术栈
- **Web服务器**: Nginx
- **应用语言**: PHP 7.1+ (编译版本)
- **前端设计**: 完全模仿hao123.com风格
- **响应式设计**: 支持桌面端和移动端
- **交互功能**: 平滑滚动、锚点跳转、高亮效果

### 后端技术栈
- **Web框架**: FastAPI 0.95.2 (Python 3.7兼容)
- **异步处理**: asyncio + httpx
- **HTML解析**: BeautifulSoup4 + lxml
- **并发控制**: 真正的并行搜索机制
- **超时管理**: 智能超时和任务取消

### 搜索引擎集成
- **百度搜索**: 主要搜索引擎，中文内容优势
- **搜狗搜索**: 备用搜索引擎，补充结果
- **360搜索**: 备用搜索引擎，增加覆盖率

## ⚡ 核心特性

### 1. 实时搜索架构
- **无存储依赖**: 不需要数据库、缓存、索引
- **实时获取**: 每次搜索都从搜索引擎实时获取
- **快速响应**: 5秒内返回搜索结果
- **智能超时**: 单个请求5秒，总超时5秒

### 2. 多引擎聚合策略
- **并行搜索**: 同时向3个搜索引擎发送请求
- **结果合并**: 智能去重和排序
- **优先级排序**: 搜狗 > 360 > 百度
- **来源标记**: 显示每个结果的来源引擎

### 3. 官方网站智能识别
- **多维度评分**: 域名、关键词、内容分析
- **中英文支持**: 支持中英文官方网站识别
- **权威性验证**: 基于TLD和关键词匹配
- **实时过滤**: 实时过滤非官方网站

### 4. 用户体验优化
- **hao123风格**: 完全模仿hao123.com的设计
- **响应式设计**: 自适应各种屏幕尺寸
- **移动端优化**: 防止搜索框放大、按钮溢出
- **快速加载**: 优化的CSS和JavaScript

## 🚀 部署架构

### 开发环境
```bash
# 启动后端服务
cd backend
python -m venv venv
source venv/bin/activate
pip install -r requirements_realtime.txt
uvicorn api.main_realtime:app --host 0.0.0.0 --port 8000

# 启动前端服务
# 配置Nginx指向frontend/public目录
# 访问 http://localhost
```

### 生产环境
- **后端**: Python + FastAPI + uvicorn
- **前端**: Nginx + PHP-FPM
- **反向代理**: Nginx配置反向代理到后端API
- **进程管理**: systemd或supervisor管理服务

## 🔄 搜索流程

### 1. 用户搜索流程
```
用户输入 → 前端验证 → 发送API请求 → 后端接收 → 并行搜索 → 结果处理 → 返回前端 → 显示结果
```

### 2. 后端处理流程
```
接收请求 → 启动3个搜索任务 → 并行执行 → 收集结果 → 去重排序 → 官方网站过滤 → 返回结果
```

### 3. 搜索引擎调用
```
百度搜索 → 解析HTML → 提取结果
搜狗搜索 → 解析HTML → 提取结果  } 并行执行
360搜索  → 解析HTML → 提取结果
```
