# 实时搜索架构设计

## 概述

实时搜索版本完全摒弃了数据存储依赖，每次搜索请求都会实时从6个搜索引擎获取结果，然后通过AI算法进行官方网站识别和权威性评分。

## 架构特点

### 1. 无存储依赖
- 不需要MySQL数据库
- 不需要Elasticsearch索引
- 不需要Redis缓存
- 完全基于实时搜索

### 2. 多搜索引擎聚合
- **国际搜索引擎**：Google, Bing, DuckDuckGo
- **中文搜索引擎**：百度, 搜狗, 360搜索
- **并行搜索**：6个引擎同时搜索，提高效率和覆盖率

### 3. 实时官方网站识别
- 基于多维度评分算法
- 实时内容分析
- 权威性验证
- 支持中英文官方网站识别

## 技术架构

```
用户请求 → PHP前端 → FastAPI后端 → 6个搜索引擎 → AI分析 → 结果返回
                ↓
           实时搜索服务
                ↓
         ┌─────────────────┐
         │  搜索引擎聚合   │
         │ Google + Bing   │
         │ + DuckDuckGo    │
         │ + 百度 + 搜狗   │
         │ + 360搜索       │
         └─────────────────┘
                ↓
         ┌─────────────────┐
         │  AI官方网站识别 │
         │  权威性评分     │
         │  结果排序       │
         └─────────────────┘
```

3. **DuckDuckGo** - 隐私保护搜索引擎

### 中文搜索引擎
4. **百度** - 中国最大的搜索引擎
5. **搜狗** - 腾讯旗下搜索引擎
6. **360搜索** - 奇虎360搜索引擎

## 核心组件

### 1. 实时搜索服务 (RealtimeSearchService)

**功能**:
- 并行搜索6个搜索引擎
- 结果去重和合并
- 官方网站过滤
- 权威性评分排序

**关键方法**:
```python
async def search(query: str, max_results: int = 10) -> Dict[str, Any]
async def _fetch_results(session: httpx.AsyncClient, engine: str, query: str)
def _parse_results(html_content: str, engine: str) -> List[Dict]
def _is_official_website(link: str, query: str) -> bool
```

### 2. 搜索引擎解析器

**Google解析器**:
- 解析搜索结果HTML
- 提取标题、链接、摘要
- 处理Google重定向URL

**Bing解析器**:
- 解析Bing搜索结果
- 提取结构化数据
- 处理特殊格式

**DuckDuckGo解析器**:
- 解析隐私搜索引擎结果
- 提取干净的数据
- 处理无追踪格式

**百度解析器**:
- 解析百度搜索结果
- 处理中文内容
- 处理百度重定向链接

**搜狗解析器**:
- 解析搜狗搜索结果
- 提取中文网站信息
- 处理搜狗特有格式

**360搜索解析器**:
- 解析360搜索结果
- 处理中文官方网站
- 提取相关描述信息

### 3. 官方网站识别器

**多维度评分**:
- 域名权威性 (40%)
- 内容质量 (30%)
- 链接关系 (20%)
- 技术指标 (10%)

**实时分析**:
- 域名后缀检测 (.gov, .edu, .org, .gov.cn, .edu.cn)
- 内容关键词分析
- 结构化内容识别
- 技术指标验证
- 中文官方网站关键词识别

**中文支持**:
- 支持中文域名识别
- 中文关键词匹配
- 中文官方网站特征识别

## API接口

### 搜索接口
```http

    "max_results": 20
}
```

