# 实时搜索架构设计

## 概述

实时搜索版本完全摒弃了数据存储依赖，每次搜索请求都会实时从多个搜索引擎获取结果，然后通过AI算法进行官方网站识别和权威性评分。

## 架构特点

### 1. 无存储依赖
- 不需要MySQL数据库
- 不需要Elasticsearch索引
- 不需要Redis缓存
- 完全基于实时搜索

### 2. 多搜索引擎聚合
- Google搜索引擎
- Bing搜索引擎  
- DuckDuckGo搜索引擎
- 并行搜索，提高效率

### 3. 实时官方网站识别
- 基于多维度评分算法
- 实时内容分析
- 权威性验证

## 技术架构

```
用户请求 → PHP前端 → FastAPI后端 → 多搜索引擎 → AI分析 → 结果返回
                ↓
           实时搜索服务
                ↓
         ┌─────────────────┐
         │  搜索引擎聚合   │
         │  Google + Bing  │
         │  + DuckDuckGo   │
         └─────────────────┘
                ↓
         ┌─────────────────┐
         │  AI官方网站识别 │
         │  权威性评分     │
         │  结果排序       │
         └─────────────────┘
```

## 核心组件

### 1. 实时搜索服务 (RealtimeSearchService)

**功能**:
- 并行搜索多个搜索引擎
- 结果去重和合并
- 官方网站过滤
- 权威性评分排序

**关键方法**:
```python
async def search(query: str, max_results: int = 10) -> Dict[str, Any]
async def _search_engine(engine: Dict, query: str, max_results: int) -> List[Dict]
def _parse_search_results(html: str, engine_name: str) -> List[Dict]
async def _filter_official_websites(results: List[Dict]) -> List[Dict]
```

### 2. 搜索引擎解析器

**Google解析器**:
- 解析搜索结果HTML
- 提取标题、链接、摘要
- 处理Google重定向URL

**Bing解析器**:
- 解析Bing搜索结果
- 提取结构化数据
- 处理特殊格式

**DuckDuckGo解析器**:
- 解析隐私搜索引擎结果
- 提取干净的数据
- 处理无追踪格式

### 3. 官方网站识别器

**多维度评分**:
- 域名权威性 (40%)
- 内容质量 (30%)
- 链接关系 (20%)
- 技术指标 (10%)

**实时分析**:
- 域名后缀检测
- 内容关键词分析
- 结构化内容识别
- 技术指标验证
