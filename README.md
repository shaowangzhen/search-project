# 官方网站搜索引擎

## 项目概述

本项目旨在构建一个专注于官方网站检索的搜索引擎，解决当前搜索引擎过度商业化、广告过多的问题。通过AI技术和大数据分析，为用户提供纯净、权威的官方网站搜索结果。

## 核心特性

- 🎯 **专注官方网站**：只索引和展示官方网站内容
- 🚫 **无广告干扰**：纯净的搜索体验
- 🤖 **AI智能分析**：利用AI技术进行内容分析和权威性验证
- ⚡ **高性能**：快速响应和准确结果
- 🔍 **智能排序**：基于权威性和相关性的智能排序算法

### 技术栈选择

#### 前端层 (LNMP)
- **Web服务器**: Nginx
- **应用服务器**: PHP-FPM 8.1+
- **数据库**: MySQL 8.0
- **前端框架**: Vue.js 3 + Element Plus
- **缓存**: Redis

#### 后端层 (Python)
- **Web框架**: FastAPI
- **爬虫框架**: Scrapy + Selenium
- **AI/ML**: 
  - 内容分析: spaCy + transformers
  - 权威性验证: 自定义算法
  - 文本相似度: sentence-transformers
- **任务队列**: Celery + Redis
- **搜索引擎**: Elasticsearch

#### 数据存储
- **关系数据库**: MySQL (用户数据、配置)
- **搜索引擎**: Elasticsearch (网页内容索引)
- **缓存**: Redis (热点数据、会话)
- **文件存储**: 本地存储 + CDN

## 核心模块设计

### 1. 爬虫模块 (Python)
- **网站发现**: 基于种子URL和域名扩展
- **内容抓取**: 智能爬取，避免反爬虫
- **官方网站识别**: 基于域名、内容、链接等多维度判断
- **增量更新**: 定期更新已索引网站

### 2. 内容分析模块 (Python)
- **文本预处理**: 清洗、分词、去噪
- **内容分类**: 识别页面类型和主题
- **权威性评估**: 基于多个指标的综合评分
- **去重处理**: 识别和合并重复内容

### 3. 搜索服务模块 (Python)
- **查询处理**: 查询解析和优化
- **相关性计算**: 基于BM25和语义相似度
- **排序算法**: 综合权威性和相关性的排序
- **结果聚合**: 结果去重和格式化

### 4. 前端界面模块 (PHP)
- **搜索界面**: 简洁的搜索框和结果展示
- **用户交互**: 搜索历史、收藏等功能
- **API接口**: 与后端Python服务通信
- **响应式设计**: 支持多设备访问

## 数据流程

1. **数据采集**: 爬虫模块定期抓取官方网站
2. **内容分析**: AI模块分析内容并评估权威性
3. **数据存储**: 将处理后的数据存储到ES和MySQL
4. **搜索查询**: 用户通过前端发起搜索请求
5. **结果返回**: 后端计算相关性并返回排序结果
