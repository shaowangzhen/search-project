# 招商银行理财产品和基金组合分析指南

## 适用场景

本工具非常适合分析招商银行APP中的理财产品和基金投资：
- 理财产品（固定收益类、净值型等）
- 公募基金（股票基金、债券基金、混合基金等）
- 现金类产品（货币基金、活期存款等）

## 如何使用

### 1. 收集你的投资信息

打开招商银行APP，记录以下信息：

#### 理财产品示例
- 产品名称：招银理财日日鑫
- 持有金额：100,000元
- 买入成本：100,000元
- 当前净值：1.02（如果是净值型）
- 年化收益率：3.5%（如果是固定收益）

#### 基金示例
- 基金代码：000001（可在APP中查看）
- 基金名称：华夏成长混合
- 持有份额：10,000份
- 持有成本：1.50元/份
- 当前净值：1.65元/份

### 2. 在工具中录入

访问 http://localhost:8001，按以下方式录入：

#### 录入理财产品
```
股票代码：LCCP001（自定义代码，方便识别）
股票名称：招银理财日日鑫

平均成本：1.00（如果不知道净值就填1）

```

#### 录入基金
```
股票代码：000001（基金代码）
股票名称：华夏成长混合
持有数量：10000（持有份额）
平均成本：1.50（买入时的净值）
当前价格：1.65（当前净值，可在APP中查看）
```

### 3. 计算当前价格的方法

如果你知道：
- **本金金额**
- **当前市值**

那么当前价格 = 当前市值 / 持有数量

例如：
- 投入：50,000元（本金）
- 当前市值：52,500元
- 持有数量：50,000（填入本金金额）
- 平均成本：1.00
- 当前价格：1.05（52,500 / 50,000）

### 6. 实用技巧

#### 追踪历史表现
建议定期（如每月1号）记录：
- 各产品的当前净值
- 总市值
- 收益率

这样可以：
- 观察组合的历史波动
- 评估投资策略效果
- 及时调整配置

#### 资产配置建议
根据风险承受能力：

**保守型（年化3-5%）**
- 理财产品：40%
- 债券基金：30%
- 货币基金：20%
- 现金：10%

**稳健型（年化5-8%）**
- 理财产品：30%
- 债券基金：30%
- 混合基金：25%
- 股票基金：10%
- 现金：5%

**进取型（年化8%+）**
- 股票基金：40%
- 混合基金：30%
- 债券基金：20%
- 现金/货币：10%

### 7. 招商银行APP数据获取

在招行APP中：

1. **查看总资产**
   - 首页 → 总资产 → 查看各产品持仓

2. **查看基金净值**
   - 理财 → 基金 → 我的基金 → 点击具体基金
   - 可看到：持有份额、单位净值、持仓成本

3. **查看理财产品**
   - 理财 → 我的理财 → 点击具体产品
   - 可看到：持有金额、累计收益、年化收益率

4. **导出数据**
   - 部分产品支持导出持仓明细
   - 可以方便批量录入

### 8. 定期分析流程

建议每月进行一次组合分析：

1. **收集数据**（10分钟）
   - 从招行APP记录各产品净值
   - 更新到分析工具

2. **分析指标**（5分钟）
   - 查看总收益率
   - 检查资产配置比例
   - 观察风险指标变化

3. **调整策略**（根据需要）
   - 如果某类资产占比过高，考虑减仓
   - 如果收益不达预期，分析原因
   - 根据市场情况调整配置

### 9. 注意事项

1. **理财产品特点**
   - 部分产品有封闭期，无法提前赎回
   - 净值型产品会有波动
   - 注意产品到期时间

2. **基金投资提醒**
   - 基金净值每日更新（交易日）
   - 申购赎回有确认时间
   - 注意申购费、赎回费

3. **风险控制**
   - 不要把所有钱投入高风险产品
   - 保持一定比例的现金或低风险资产
   - 分散投资，不要集中在单一产品

### 10. 常见问题

**Q: 理财产品没有净值怎么办？**
A: 使用收益率计算。例如年化3%，持有半年，当前价格填 1.015

**Q: 不知道买入成本怎么办？**
A: 可以在招行APP的交易记录中查看，或者估算一个平均值

**Q: 如何比较不同产品的表现？**
A: 使用工具的"比较功能"，创建多个组合分别放入不同产品

**Q: 工具能自动获取基金净值吗？**
A: 目前需要手动输入，未来可以接入基金数据API自动更新
